# Medicaid Supplemental Payment Reconciliation

Reconcile complex Medicaid supplemental pools and recover omitted or misallocated provider payments.

**Primary buyer:** Hospitals, states, and provider associations. **Evidence:** state plan amendments, provider eligibility, base claims, uncompensated care, upper payment limits, quality pools, directed payments, assessments, distributions, and settlements.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Program authority library
- Provider eligibility registry
- Base claim ingestion
- Uncompensated care calculation
- Upper payment limit control
- DSH limit calculation
- Directed payment methodology
- Quality pool scoring
- Provider tax interaction
- Intergovernmental transfer
- Pool allocation calculation
- State payment file matching
- Provider dispute workflow
- Cash reconciliation
- Program provider analytics

Run `./start.sh`, then open <http://127.0.0.1:4691>. API: `5691`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
